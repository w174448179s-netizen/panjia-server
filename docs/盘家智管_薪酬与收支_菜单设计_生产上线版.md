## 一、设计原则

### 1.1 与顶层域严格对齐

菜单分区与产品化架构中的 **6 个顶层业务域**一一对应，菜单操作只触发对应域的 Service/API，禁止跨域直连。

| 菜单区域 | 对应顶层域 | 依赖约束 |
|----------|------------|----------|
| 基础档案 | `panjia-people` | 被所有域依赖，自身无业务域依赖 |
| 数据导入 | `panjia-import` | 只依赖 people，不依赖下游 |
| 业绩管理 | `panjia-performance` → `panjia-commission` | import → performance → commission 单向 |
| 薪酬计算 | `panjia-payroll` | **仅依赖 people + commission**，不穿透 performance |
| 部门收支 | `panjia-ledger` | 仅依赖 contracts 事件，反向 0 依赖 |

### 1.2 三条红线

1. **状态机与权限分离**：菜单按钮只触发状态机 API（如"锁定批次"），状态合法性由领域模型 `assertCan()` 保证，不写进前端 JS 判断或 SpEL 表达式。
2. **锁定后只读**：已锁定的工资批次、已审批的结佣，菜单不提供"编辑"入口，修正一律走"调整/补发/结佣调整"新增记录。
3. **复用底座能力**：用户/角色/菜单、参数配置、数据字典、操作日志均复用 RuoYi 原生模块，不在业务域中重复建设。

### 1.3 明确排除项（依据业务需求第十二章"系统不做的事"）

| 排除项 | 原因 |
|--------|------|
| 移动端 H5 / 小程序 | 本期只做 PC 管理后台 |
| 复杂 BI 报表大盘 | 仅保留工资批次导出，无多维分析 |
| 工作流设计器 | 审批只有"通过/驳回"，用 Warm-Flow 内置 |
| 钉钉 API 对接 | 考勤/积分由人事整理 Excel 导入 |
| 个税自动申报 | 只计算金额，不连税务系统 |
| 独立操作日志模块 | 复用 RuoYi 系统日志 |

## 四、操作链路与菜单顺序（生产推荐）

菜单排列严格遵循业务事实链路，确保用户操作路径 = 数据流转路径。

```
基础档案（前置配置）
    ↓
数据导入（每月初）
    ↓
业绩管理（导入后自动流转）
    ↓
薪酬计算（月底核心）
    ↓
部门收支（工资锁定后事件驱动汇总）
    ↓
系统管理（运维与管控）
```

### 4.1 典型月度操作流程

| 步骤 | 操作菜单 | 角色 | 触发结果 |
|------|----------|------|----------|
| 1 | 贝壳业绩导入 | 财务 | 生成 ImportBatch + NormalizedRecord |
| 2 | 考勤/积分数据导入 | 人事 | 生成考勤/积分事实 |
| 3 | 业绩明细（确认） | 财务 | 归一化→PerformanceFact |
| 4 | 结佣申请 → 审批 | 财务 → 总监 | 结佣锁定（快照） |
| 5 | 算薪批次（发起计算） | 财务 | 触发 SalaryCalculationEngine |
| 6 | 工资明细（核对） | 总监/店长 | 钻取溯源 |
| 7 | 算薪批次 → 锁定 → 发放 | 总监 | 发布 PayrollLockedEvent |
| 8 | 部门收支表（自动生成） | 总监 | ledger 消费事件汇总 |

## 五、关键交互说明

### 5.1 状态机与按钮可见性

| 页面 | 状态 | 可见按钮 | 说明 |
|------|------|----------|------|
| 算薪批次 | 草稿 | 发起计算、删除 | — |
| | 已计算 | 审核、驳回 | — |
| | 已批准 | 锁定 | 锁定后禁止直接修改 |
| | 已锁定 | 发放、调整/补发 | 修正走新增记录 |
| | 已发放 | 仅查看 | 终态 |
| 结佣申请 | 待审批 | 通过、驳回 | Warm-Flow 驱动 |

> **规则：** 按钮是否可用由后端状态机 `assertCan()` 判定，前端只做展示控制，不信任前端校验。

### 5.2 锁定后修正路径

- **工资锁定后**：菜单不提供"编辑明细"入口，必须通过「调整与补发」菜单新增调整单/补发单。
- **结佣审批后**：通过「结佣调整」菜单新增调整记录，不改原始结佣事实（原始数据只读）。
- 所有修正均生成审计记录，满足"可追溯闭环"原则。

### 5.3 横切能力入口

| 能力 | 菜单位置 | 实现方式 |
|------|----------|----------|
| 授权管理 | 系统管理 → 授权管理 | LicensePort → LicenseAdapter，不侵入业务 |
| 备份恢复 | 系统管理 → 备份恢复 | BackupPort → BackupAdapter；算薪前自动触发 |
| 审计日志 | 系统管理 → 操作日志 | 复用 RuoYi，关键操作强制记录 |
