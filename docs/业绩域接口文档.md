## 1. PerformanceFactController — 业绩事实管理

路径前缀：`/perf/fact`

### 1.1 GET /perf/fact/list — 分页查询业绩事实

| 项 | 内容 |
|---|------|
| **前端场景** | 业绩调整创建表单（`performance/adjust/index.vue`）中，选择期间和员工后加载可选事实列表 |
| **权限** | `perf:fact:list` |

**入参**（FactQuery + PageQuery）：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| period | String | 否 | 归属期间 YYYY-MM |
| factType | String | 否 | 事实口径：PERF_EXPECT / PERF_REAL |
| employeeId | Long | 否 | 员工 ID |
| factStatus | String | 否 | 事实状态：ACTIVE / REVERSED |
| pageNum | Integer | 否 | 页码，默认 1 |
| pageSize | Integer | 否 | 每页条数，默认 10 |

**出参**：`PageResult<PerformanceFactDTO>`
- id, factType, period, businessDate, orderNo, contractNo, bizType, propertyAddress, feeItem, employeeId, employeeExternalCode, employeeName, deptId, roleType, roleName, shareRatio, performanceAmount, factStatus, source, adjustId

---

### 1.2 GET /perf/fact/manage/contract — 合同维度分页查询

| 项 | 内容 |
|---|------|
| **前端场景** | 新签明细/实收明细列表页（`performance/contract/index.vue`），以合同为维度展示业绩 |
| **权限** | `perf:fact:list` |

**入参**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| period | String | 是 | 归属期间 YYYY-MM |
| factType | String | 是 | PERF_EXPECT(新签) / PERF_REAL(实收) |
| deptId | Long | 否 | 门店/组别（含子部门） |
| employeeId | Long | 否 | 员工 ID |
| bizType | String | 否 | 业务类型 |
| keyword | String | 否 | 关键字（合同号/订单号/房源地址/角色） |
| factStatus | String | 否 | 状态过滤：ACTIVE / VOIDED / ALL |
| pageNum | Integer | 否 | 页码，默认 1 |
| pageSize | Integer | 否 | 每页条数，默认 20 |

**出参**：`PerformanceManagePageVO<PerformanceManageContractVO>`
- rows: contractNo, orderNo, bizType, propertyAddress, businessDate, amount, originalAmount, convertedAmount, originalConvertedAmount, employeeCount, detailCount, factStatus
- summary: employeeCount, contractCount, detailCount, totalAmount
- total

## 已删除接口

以下接口已从前端和后端删除（前端无调用，废弃老接口）：

| 接口 | 删除原因 |
|------|---------|
| `GET /perf/fact/{id}` | 详情通过合同明细懒加载替代 |
| `POST /perf/fact/build/{batchId}` | 批次消费已改为事件驱动 |
| `GET /perf/fact/summary` | 汇总数据已在分页响应中返回 |
| `GET /perf/fact/manage`（人维度） | 改为合同维度分页 |
| `GET /perf/fact/manage/details`（人维度） | 改为合同维度明细懒加载 |
| `GET /perf/adjust/{id}` | 前端使用 `/{id}/detail` 替代 |
| `GET /perf/period/{period}` | 前端使用 /list 列表替代 |
